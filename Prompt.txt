Build a Production-Grade PSAT/SAT fully adaptive Learning Platform

Create a modern, enterprise-grade educational web application using Python and Streamlit for PSAT and SAT preparation.

The application should be designed for multiple students, provide a rich user experience, support AI-powered tutoring, track performance over time, and scale for future growth.
